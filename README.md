# Device configurations for Vsmart Joy 3 (casuarina)

The Vsmart Joy 3 (codenamed "casuarina") is a mid-range smartphone from Vsmart. It's the successor to the Vsmart Joy2.

## Device specifications
| Basic                   | Spec sheet                                                                    |
| -----------------------:|:----------------------------------------------------------------------------- |
| CPU                     | Octa-core (4x1.8 GHz Kryo 250 Gold & 4x1.8 GHz Kryo 250 Silver)               |
| Chipset                 | Qualcomm SDM632 Snapdragon 632 (14 nm)                                        |
| GPU                     | Adreno 506                                                                    |
| Memory                  | 2/3/4 GB RAM                                                                  |
| Shipped Android Version | Android 9 (Pie), upgradeable to Android 10 (Q)                                |
| Storage                 | 32/64 GB eMMC 5.1                                                             |
| Battery                 | Non-removable Li-Ion 5000 mAh battery                                         |
| Display                 | 720 x 1600 pixels, 20:9 ratio (~320 ppi density)                              |
| Camera (Back)           | 13 MP, f/2.0 (wide), 8 MP f/2.2 (Ultra-wide), 2 MP, f/2.4 (Macro)             |
| Camera (Front)          | 8 MP, f/2.0                                                                   |
